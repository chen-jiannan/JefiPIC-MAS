替换 GitHub 当前工作目录

这个包是完整的当前源码树。解压后，EMsolver、Particle_transport、README.md、run.py
等应直接位于 GitHub 仓库根目录。不要把整个包再放进现有仓库的一个新子目录。

用 Git 更新已有仓库时，在仓库工作目录移除旧的受跟踪文件，放入本包内容，
核对变更后提交和 push。保留仓库自身 .git/，它保存提交历史；不需要删除历史或强制推送。
本工具没有连接或修改任何远程仓库。旧的复现包装目录不应与新入口并列保留。

Mendeley 第二版已点击 Publish：如果已经公开，文件不能原地覆盖；
调整它须发布后续版本。如果仍在审核，先确认平台是否允许退回草稿。
目录调整不改变第二版的数据有效性，不必只为目录结构立即再次发布。
另附清晰目录的数据包供将来更新使用，未自动发布，也未预先分配版本 DOI。

如果保留已经发表的第二版，论文仍可引用其实际 DOI；GitHub 的当前目录结构
与已归档包可以不同，provenance 的路径映射说明二者的对应关系。
