# Reference data

These files are compact manuscript-facing evidence for the public GitHub
release. The fuller numerical outputs are in the companion Mendeley-Data
package.

`full_em/` contains the principal source-closure, backend-parity, broadband,
two-way closure, article-scale, and response-stationarity reports.

`temporal/` contains the causal Retarded-MOT long-horizon and harmonic
regressions.

`spatial_auxiliary/` contains the controlled collocation-overfit result.

`quasi_auxiliary/` contains the frozen 3/6/9 MHz spatial-diagnostic and
particle/seed sensitivity evidence. These files retain their original
quasi-electrostatic plasma-grid-source scope and are not full-EM PIC results.

Raw archived reports are preserved where useful. Manuscript-facing rounded
values are summarized in `FINAL_KEY_NUMBERS.csv`.
